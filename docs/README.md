## How to keep these up to date

- **New decision:** add a row to `decision-log.md` with the next D number and today's date. Mention it in the issue, e.g. "see D27".
- **Changed requirement:** edit `prd.md` directly. Git keeps the history, so don't make v0.3 copies.
- **New feature spec:** add a folder under `specs/` with a `README.md`, and link it in the table above.
- Edit on GitHub (pencil icon) or in a pull request.
