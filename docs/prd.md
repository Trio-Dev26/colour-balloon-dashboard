### Decisions already made (3 Oct 2026)

| # | Decision |
| --- | --- |
| D1 | Content structure is **Level + Category → Module → Unit → Lesson**. |
| D2 | Teachers access teacher materials (teaching guides, answer keys, content resources) through a **Teacher Membership** or a **per-module licence**, as in the Product Model. |
| D3 | Students pay by **subscription only** (1, 3 or 12 months) with a 14-day free trial. |
| D4 | Worksheets and resources marked downloadable are **real downloads**. |
| D5 | A unit is complete when **all lessons are done and every Required quiz is passed**. |
| D6 | Lessons in a unit open **one at a time**. |
| D7 | The student must **pass the Chapter End Test** to get the badge and certificate and unlock the next module. |
| D8 | **Badges and certificates are in the first release.** |
| D9 | **Reopened 5 Oct 2026, not confirmed:** whether there is a parent account or only Student and Teacher accounts (plus Admin). Treat as open. |
| D10 | **Reopened 5 Oct 2026, not confirmed:** currencies (THB, USD and MMK proposed). Treat as open. |
| D11 | **Levels and categories are fixed** system values. Admins cannot create, edit or delete them. |
| D12 | There is **no fixed lesson format** (no 8-step structure). Lesson content is flexible. |
| D13 | **Codes are generated by the system and never change.** Format: module `{Level letter}{Category letter}{nn}` e.g. `FM01`; unit `FM01-U01`; lesson `FM01-U01-L01`; unit quiz `FM01-U01-Q01`; Chapter End Test `FM01-CET`. No company prefix. Lists show the short part (M01, U03); order number is separate from the code. |
| D14 | **Fixed levels:** Foundation (F), Beginner (B), Elementary (E), Intermediate (I). **Fixed categories:** Main Lesson (M), Reading (R), Writing (W), Speaking (S), Grammar (G), Poetry (P). Letters are used in codes (D13). |
| D15 | **The Teacher side is in the first release** (decided 4 Oct 2026). |
| D16 | **Quiz type is chosen explicitly.** Quiz setup has a Quiz type field: *Unit quiz* (Unit field required) or *Chapter End Test* (Unit field hidden, code `FM01-CET`). Each module has at most one Chapter End Test; once it exists the option is disabled. In the database, a quiz with no unit is the CET. Every question belongs to a unit; the Chapter End Test is built by picking questions from all the module's units (8 Oct). |
| D17 | **Module status.** *Draft*: never published, admin only. *Published*: visible to students and teachers; needs at least 1 unit with at least 1 lesson. *Unpublished*: was published, now hidden; new students cannot start it, enrolled students keep progress and it returns when republished. The list toggle switches Published ↔ Unpublished; a module never returns to Draft. |
| D18 | **Deleting content.** *Draft module*: admin can delete the module or any unit, lesson or quiz in it, even with content under it; a confirmation lists what will be deleted. *Published or Unpublished module*: the module cannot be deleted, only unpublished; a unit, lesson or quiz inside it can be deleted only if no student has started it (no progress or attempt records). A question used in any quiz cannot be deleted until removed from those quizzes. |
| D19 | **Downloads.** Downloadable groups accept PDF, audio and images only; no editable Word/PowerPoint files. Every download is logged (user, file, time). No watermark in the first release; revisit if logs show sharing. |
| D20 | **Quiz scope.** A unit quiz belongs to exactly one unit; the Chapter End Test covers the whole module. The Figma unit picker becomes single-select. |
| D21 | **Quiz total.** The quiz total is calculated automatically as the sum of its question points and shown live; admins do not type it. The pass mark is a percentage (e.g. 70%). |
| D22 | **Scoring.** Multiple choice has exactly one correct answer (first release). Matching, sequence and multi-blank give partial points: each correct pair/position/blank earns its share of the question points. True/False and single-blank are all or nothing. |
| D23 | **Fill-in-the-blank.** Admin marks each blank with `___`; the form shows one answer box per blank. Each blank can have several accepted answers. Marking ignores extra spaces, invisible characters and English case, but not Myanmar vowel signs or tone marks. Zawgyi input is converted to Unicode before checking. |
| D24 | **Quiz attempts.** Unit quizzes: unlimited attempts. Chapter End Test: 3 attempts, then locked 24 hours, then 3 more (repeats; never a permanent block); lock screen links back to the lessons. Admin can unlock early. Best score counts; a later lower score never removes a pass. 3 attempts / 24 hours start as defaults and may become admin settings. |
| D25 | **Lesson completion.** The student opens every student-view file (each shows a tick); then a "Finish lesson" button is enabled; pressing it completes the lesson and unlocks the next. Opening a video counts (no watch-to-end). Downloadable files are not required. |
| D26 | **Progress %.** Module progress = completed steps ÷ total steps, where steps are lessons + Required quizzes + the Chapter End Test. 100% only when the Chapter End Test is passed. The same number is used on the student dashboard, admin user page and reports. |
| D27 | **Bulk import per level.** No single all-in-one import. Units: "Import units" on the Unit list page (module code column; one file can cover many modules). Lessons: "Import lessons" on the Lesson list page (unit code column, e.g. FM01-U01; 8 Oct). Modules and units must already exist; codes are checked in one lookup per file (7 Oct). Questions: "Import questions" on the Question list page, with a required "Unit code" column (every question belongs to a unit; one module per upload when there is media; 8 Oct), Excel with one sheet per type + a zip of media referenced by file name. Modules: no import (form). Lesson files: not imported; added on the normal lesson screen (captions and per-file settings). Each import screen has a "Download template" button. All imports share one check-and-preview step; nothing is saved if any row has an error. Build after the normal create/edit screens; questions import first. |

## 1. Product Overview

| | |
| --- | --- |
| Purpose | Teach young learners to read and write Myanmar (မြန်မာစာ) online through a structured, step-by-step curriculum, and let teachers teach the same curriculum from the platform. |
| Target users | Young learners at KG Foundation to Year 2 level; teachers; Colour Balloons administrators. |
| Main goals | Sell student subscriptions and teacher access · let admins build and maintain all content without developers · track each learner's progress and reward completion · keep content on the platform with access control. |
| Description | A responsive web app (English and Myanmar). Admins build the curriculum: modules, units, lessons, files, questions and quizzes. Students unlock units in order, watch and listen to lessons, download worksheets, take auto-marked quizzes, and earn a badge and certificate per module. Teachers get the teacher layer of every lesson (guides, answer keys, resources) without unlocking. |

## 4. User Flows

**Admin – build content** (Figma)
Login → Create module (level, category, code, image, EN/MY text) → Create units → Arrange units → Create lessons → Upload student and teacher files → Create questions → Create quiz and add questions → Preview as learner → Publish module

**Student – learn**
Student registers → Starts 14-day trial or buys a plan → Opens catalog → Module → Unit 1 → Lesson 1 → 2 → 3 (each unlocks after the previous) → Download worksheet → Pass Required unit quiz → Next unit unlocks → … → Pass Chapter End Test → Badge + certificate → Next module unlocks
Plan expires → content locks; progress, badges and certificates stay.

**Teacher – teach**
Register → Start 14-day trial, subscribe, or buy a module licence → Browse curriculum (all open) → Open lesson → View guide / answer key / resources → Download or print → Present slide lesson
Membership expires → access ends. Module licence → lifetime access to that module's teacher layer.

**Admin – operate**
Login → Dashboard → Users → Plans & prices → Subscriptions and payments → Reports

## 6. Business Rules

| ID | Rule | Label |
| --- | --- | --- |
| BR-01 | Only Published modules (and their units, lessons and quizzes) are visible to learners and teachers. When a module is Unpublished, students already in it keep their progress, and it is restored when it is republished. | C (D17) |
| BR-02 | Each module belongs to one level and one category. | C |
| BR-03 | Units unlock in order; unit 1 is open. | C |
| BR-04 | Lessons unlock in order inside an open unit; lesson 1 is open. | C |
| BR-05 | A unit is complete when all its lessons are complete and every Required quiz is passed. Optional quizzes never block. | C |
| BR-06 | A module is complete when its Chapter End Test is passed. Completion awards the badge and certificate and unlocks the next module. | C |
| BR-07 | Teachers are not subject to unlocking. | C |
| BR-08 | Students never see teacher files; teachers never see student videos, audio or quizzes. | C |
| BR-09 | Student access requires an active trial or subscription. Teacher access requires an active trial, membership, or a licence for that module. | C |
| BR-10 | When a plan expires, content locks but progress, scores, badges and certificates remain. | C |
| BR-11 | Students buy subscriptions only; there is no per-module purchase for students. | C |
| BR-12 | A free trial lasts 14 days and never charges automatically. | C |
| BR-13 | Quiz passing score cannot exceed its total score; total points of its questions cannot exceed its total score. | C |
| BR-14 | A student cannot exceed a quiz's allowed attempts. | C |
| BR-15 | Codes are unique: module, level, category and quiz codes across the system; unit codes per module; lesson codes per unit. | C |
| BR-16 | Files over 200 MB are rejected; module and question images are JPG/PNG ≤ 20 MB. | C |
| BR-17 | Only admins create, edit, delete or publish content. | C |
