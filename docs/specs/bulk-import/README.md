# Colour Balloons · Bulk Import Spec

For developers and designer. Owner: Kay Zin · 8 October 2026
Design: https://claude.ai/artifact/8PeRyZyxNgxwyDZqXjF34G · Templates: [templates/](templates/)

## 1. What to build

| Import | Page | Template | Row belongs to |
| --- | --- | --- | --- |
| Units | Unit list → **Import units** | Units | `Module code` (e.g. FM01) |
| Lessons | Lesson list → **Import lessons** | Lessons | `Unit code` (e.g. FM01-U01) |
| Questions | Question list → **Import questions** | Questions (5 sheets) + optional media zip | `Unit code` (e.g. FM01-U01) |

* Not imported: modules (normal form), lesson files (normal lesson screen), quizzes (built on screen).
* Each import: popup with **Download template** + upload → Check screen → Import.
* One file can cover many modules/units.

## 2. Rules

* **All-or-nothing.** Validate every row first. Save only if all rows are valid, in one transaction.
* **Draft.** New units and lessons are Draft.
* **Parent must exist.** Module before units, unit before lessons and questions. Every question belongs to a unit. The Chapter End Test is built on screen from the module's unit questions.
* **Codes.** Generated by the system, never in Excel, not shown on the Check screen. Assigned at save (next free number, lock the module row), never reused.
* **Performance.** Look up all codes in a file with one query (`WHERE code IN (...)`), never row by row.
* **Media.** Zip of images/audio, referenced by exact file name. Limit about 200 MB (about one module). Large zips run in the background with a progress bar.
* **Error list.** By sheet and row, with how to fix; downloadable as .xlsx.
* **Import record.** File name, admin, date, result.

## 3. Templates → database

**Units:** Module code → `units.module_id` · Unit no. → `sequence` · Unit title (MY)* → `title_my` · Unit title (EN) → `title_en` · Unit description (EN/MY) → `description_en/my`

**Lessons:** Unit code → `lessons.unit_id` · Lesson no. → `sequence` · Lesson title (EN)* → `title_en` · Lesson title (MY) → `title_my` · Lesson description (EN/MY) → `description_en/my`

**Questions:** every sheet starts with Unit code → `unit_id` (+ `module_id`) · Points → `default_points` · Question prompt → `prompt` · Question media → `question_media`

| Sheet | `question_type` | Own columns | Stored as `question_options` |
| --- | --- | --- | --- |
| Multiple choice | 1 | Option A–D text + image, Correct (A–D) | label, media_asset_id, is_correct |
| True False | 2 | Answer | "True" / "False", one is_correct |
| Fill blank | 3 | Blank 1–3 answers (alternatives with the bar character) | `___` → `{{1}}`…; blank_index per accepted answer |
| Sequence | 4 | Item 1–6 in correct order | sequence = correct position |
| Matching | 5 | Left/Right 1–5, text + image | side left/right, shared match_key |

## 4. Validation

* Required column empty.
* Module code / unit code not found.
* Unit/lesson no. repeated, already used, or not a number.
* Media file not in zip, or not an image/audio file.
* Multiple choice: Correct empty, not A–D, or points to an empty option.
* Option with no text and no image; fewer than 2 options, pairs or items.
* Fill blank: number of `___` differs from answers filled.
* True False answer not True/False; Points not a number above 0.

Fill blank answers get the same cleaning as marking (D23): trim spaces and invisible characters, ignore English case, convert Zawgyi to Unicode.

## 5. Build order

1. Normal create/edit screens first (import reuses their validation).
2. Questions import: True False and Multiple choice, then Sequence, Fill blank, Matching. Unbuilt sheets show "not supported yet".
3. Units and lessons import.
